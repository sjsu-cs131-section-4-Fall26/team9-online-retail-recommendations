# Dataset Download Instructions

## UCI Online Retail II

Source: https://archive.ics.uci.edu/dataset/502/online+retail+ii

The Online Retail II dataset is licensed under Creative Commons Attribution 4.0. The dataset should be credited to Daqing Chen and the UCI Machine Learning Repository.

The dataset contains approximately 1,067,371 transaction records and is approximately 43.5 MB. It should be downloaded locally to the IBM machines for analysis.

## Manual Download

1. Open the UCI dataset page.
2. Download the `online_retail_II.xlsx` file.
3. Create a local raw-data directory:

```bash
mkdir -p data/raw
